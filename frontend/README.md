# Lavatec - Laundry Management System

A web application for managing laundry operations.

## Technologies Used

- React
- TypeScript
- Vite
- Chakra UI
- React Router
- Supabase
- React Hook Form
- Zod
- React Query
- Date-fns

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm (v7 or higher)
- Supabase account

### Supabase Setup

1. Create a new project in [Supabase](https://supabase.com/)
2. Get your project URL and anon key from the project API settings
3. Copy `.env.example` to `.env.local` and update the variables:
   ```
   VITE_SUPABASE_URL=your_supabase_url_here
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
   ```

### Installation

1. Clone the repository
   ```
   git clone https://github.com/yourusername/lavatec.git
   cd lavatec
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Set up environment variables
   ```
   cp .env.example .env.local
   ```
   Then edit `.env.local` with your Supabase credentials

4. Run the development server
   ```
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173` (or the URL shown in your terminal)

## Project Structure

- `src/` - Source files
  - `components/` - Reusable UI components
  - `features/` - Feature-based components
  - `pages/` - Page components
  - `hooks/` - Custom hooks
  - `utils/` - Utility functions
  - `services/` - API calls
  - `types/` - TypeScript interfaces
  - `contexts/` - React contexts
  - `assets/` - Static assets

## Environment Variables

The application uses the following environment variables:

- `VITE_SUPABASE_URL`: Your Supabase project URL
- `VITE_SUPABASE_ANON_KEY`: Your Supabase project anonymous key
- `VITE_APP_NAME`: Application name
- `VITE_APP_DESCRIPTION`: Application description
- `VITE_ENVIRONMENT`: Current environment (development, production)

   ```
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173` (or the URL shown in your terminal)
